# Personal Task Manager

## Description

Personal Task Manager is a React-based web application for organizing and managing daily tasks.

The application allows users to add, edit, complete, delete, and filter tasks. Each task can also be assigned to a category. Tasks are saved using browser localStorage, so they remain available after refreshing the page.

## Features

- Add new tasks
- Assign categories to tasks
- Edit existing tasks
- Complete and undo tasks
- Delete tasks
- Filter tasks by All, Active, and Completed
- Display active and completed task counts
- Save tasks using localStorage
- Responsive design for desktop and mobile screens

## Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- Vite
- Browser localStorage
- Git and GitHub
